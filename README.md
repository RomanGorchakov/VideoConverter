## О проекте

Video Converter GUI — это программное приложение, разработанное в рамках выпускной квалификационной работы по теме: «Разработка кроссплатформенного GUI для видео-конвертера с системой очередей задач». Программа предназначена для удобной конвертации видеофайлов через графический интерфейс пользователя без необходимости работы с командной строкой. Основная цель проекта — предоставить простой, удобный и кроссплатформенный инструмент для обработки видеофайлов с возможностью автоматизации последовательной обработки нескольких задач.

## Основные возможности

1) Конвертация видеофайлов в различные форматы
2) Кроссплатформенная работа (Windows / Linux / macOS)
3) Графический пользовательский интерфейс (GUI)
4) Поддержка очередей задач
5) Пакетная обработка нескольких файлов
6) Гибкая настройка параметров конвертации
7) Отображение прогресса выполнения
8) Интеграция с FFmpeg

## Архитектура приложения

Приложение разработано с использованием архитектурного паттерна MVVM (Model–View–ViewModel).

Основные компоненты системы:
* View — графический интерфейс пользователя;
* ViewModel — обработка логики взаимодействия интерфейса;
* Model — модели данных и задачи конвертации;
* Conversion Service — запуск и управление процессом FFmpeg;
* Queue Manager — управление очередью задач.

## Процесс установки

1. Клонирование репозитория
2. Создание виртуального окружения
3. Установка зависимостей
4. Установка FFmpeg.

## Использование

1. Запустите приложение через команду "python main.py" в командной строке
2. Добавьте видеофайлы через опцию "Добавить"
3. Настройте параметры конвертации через опцию "Настройки"
4. Добавьте задачи в очередь
5. Запустите обработку через опцию "Старт"
6. Дождитесь завершения конвертации.
