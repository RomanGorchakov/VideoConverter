# Changelog

## [1.0.0] - 2026-06-07

### Добавлено

* Реализован графический интерфейс пользователя на PySide6.
* Добавлена поддержка конвертации видео через FFmpeg.
* Реализована система очередей задач.
* Добавлена пакетная обработка файлов.
* Реализована настройка формата выходного файла.
* Реализована настройка разрешения видео.
* Реализована настройка битрейта.
* Реализована настройка FPS.
* Добавлено отображение прогресса выполнения задач.
* Реализовано хранение настроек приложения.
* Добавлено модульное тестирование основных компонентов.

### Изменено

* Первоначальный публичный релиз проекта.

### Исправлено

* Исправлены ошибки, выявленные в процессе тестирования перед выпуском версии 1.0.0.
